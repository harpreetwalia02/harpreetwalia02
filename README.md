# Enablement Session - Code Generation (CG-13)

## Java Hello World Program

This repository contains a simple Java program created for the enablement session on code generation.

### Files
- `HelloWorld.java` - The main Java program that prints "Hello World"

### How to Run
```bash
# Compile the Java program
javac HelloWorld.java

# Run the compiled program
java HelloWorld
```

### Expected Output
```
Hello World
```
